# Fitness Tracker

A web-based fitness and health tracking application built using **HTML, CSS, and JavaScript**.

## About the Project

Fitness Tracker is designed to help users monitor different aspects of their fitness journey from a single dashboard. It combines activity tracking, workouts, nutrition, hydration, and health-related information in one application.

## Key Use Cases

### Daily Activity Tracking
Track daily steps, walking distance, and activity progress.

### Workout Tracking
Log workouts and monitor exercise activities and progress.

### Nutrition & Diet
Record meals and keep track of nutrition and calorie-related information.

### Hydration Tracking
Monitor daily water intake and compare it with hydration goals.

### Health & Wearable Data
View information such as heart rate, sleep, and wearable activity data.

## Technologies Used

- HTML
- CSS
- JavaScript
